Qué datos se recogen y para qué

El formulario de esta página es actualmente una demostración visual: el código solo muestra un mensaje en el navegador y no transmite ni almacena el nombre, correo, empresa, selección o mensaje introducidos. No envíes información confidencial mediante ese formulario. Si escribes directamente al correo publicado, se tratarán los datos que incluyas para responder a tu consulta y, si procede, preparar los pasos previos que solicites para una posible contratación.

La base jurídica para responder a una consulta será la aplicación de medidas precontractuales solicitadas por la persona interesada o, según el caso, el interés legítimo en gestionar y contestar comunicaciones profesionales. Si se inicia una relación contractual, los datos necesarios se tratarán para ejecutarla y cumplir las obligaciones legales aplicables. No se usarán estos datos para enviar publicidad no solicitada.

Destinatarios, conservación y transferencias

El sitio carga recursos técnicos externos de Google Fonts, Tailwind CSS CDN y unpkg (Lucide). La conexión a esos servicios puede comunicar datos técnicos de la solicitud, como la dirección IP, al proveedor correspondiente. El portal de demostración también se conecta a Supabase para consultar el cliente, sus facturas y sus documentos ISO seleccionados. La empresa que se elige en la demo no verifica la identidad; no introduzcas datos personales o confidenciales en esa demostración. No se ha identificado en el código una herramienta de analítica ni publicidad. El proveedor de alojamiento y sus condiciones deben confirmarse por el titular; por tanto, no es posible concretar aquí destinatarios adicionales ni ubicaciones de tratamiento.

Los mensajes recibidos por correo se conservarán durante el tiempo necesario para responder y gestionar la relación, y posteriormente durante los plazos exigidos por ley o necesarios para atender posibles reclamaciones. No se aplican decisiones automatizadas ni elaboración de perfiles en este sitio.

Tus derechos

Puedes solicitar el acceso, rectificación, supresión, oposición, limitación del tratamiento y, cuando proceda, portabilidad de tus datos escribiendo a info@kodigolabs.es e indicando el derecho que deseas ejercer. Podremos pedir información razonable para verificar tu identidad. También puedes presentar una reclamación ante la Agencia Española de Protección de Datos (aepd.es). Esta información debe revisarse si el formulario se conecta a un sistema real o se incorporan nuevas herramientas.
